# Mayil Designer Studio

A single-page static website for a fashion studio, built with HTML and CSS.

## Project structure

- `index.html` — main landing page
- `css/style.css` — styles for the page
- `assets/Images/logo-placeholder.svg` — placeholder logo image

## Notes

- The site is ready for GitHub Pages if you publish this repository.
- Update the logo by replacing `assets/Images/logo-placeholder.svg` with your own image and keeping the same path.
- No JavaScript is currently included, so the site is a clean static landing page.

## How to use

1. Open `index.html` in your browser to preview locally.
2. Commit the project to GitHub.
3. If you want GitHub Pages, enable it from the repository settings and use the `main` branch.
